# 400 预警指南·进阶版

## 适用人群

已经在高频使用 Codex，经历过至少一次对话截断，知道"400"是什么，想系统性地管理对话生命周期。

---

## 核心理念

**对话是无状态的会话，文件是持久的记忆。**

不是等截断了再救，而是在运行过程中主动管理对话状态。每个重要节点都写盘，截断后新对话通过文件恢复上下文。

---

## 预警信号系统

### 宏观信号（对话年龄维度）

- **持续 3-5 天的高频使用**：每天深入对话，3-5 天基本接近上限
- **30-50 轮以上的深层讨论**：每轮含长思考、长回答，比短轮对话更快消耗 Token
- **内容产出丰富的对话**：写代码、写文档、长文分析，每轮消耗量大幅增加
- **一次对话解决多个话题**：A→B→C→D 不相关话题，每个话题都要花 Token 重新建立上下文

### 微观信号（对话体验维度）

- AI 开始出现"记不清前面说了什么"的迹象
- AI 的回答变短、不愿意深入展开
- AI 主动建议"要不要把这个总结一下写到文件"
- 你自己也开始觉得"前面聊的内容好像远了"

### 硬性触发条件（遇到即执行写盘）

1. 完成了任何阶段性成果（调研完成、方案确定、代码跑通）
2. 做出了不可逆的判断（决定投钱、决定不做某件事）
3. 遇到了需要切换话题的转折点
4. 对话状态发生变化（认知有结构性更新）
5. AI 主动提及"对话快超限了"

## 写盘动作规范

### SESSION_LOG 标准结构

```markdown
# SESSION_LOG

共享知识库：/path/to/共享知识库.md

## [日期] -- [本轮主要事件]

### 关键进展
- 完成了什么
- 发现了什么
- 产出了什么

### 重要决策
- 决定了什么
- 理由（一句话）

### 未完成待办
- [ ] 下一步做什么
- [ ] 需要谁配合
```

### 四种写盘场景

| 场景 | 触发条件 | 详细程度 | 写入位置 |
|------|---------|---------|---------|
| **即时写盘** | 用户说了重要的话 / 做了重要产出 | 简短 — 标题+关键结果 | SESSION_LOG |
| **阶段总结写盘** | 完成一个里程碑 | 中等 — 碎片串成逻辑链 | SESSION_LOG |
| **预警写盘** | 对话接近上限 | 极简 — "两句话核心" | SESSION_LOG |
| **项目沉淀写盘** | 项目有可独立存储的细节 | 完整 — 可被独立阅读 | 项目文件 → records.md |

### 写盘质量标准

合格写盘必须满足：
- ✅ 下一轮对话能理解"上轮发生了什么"
- ✅ 下一轮对话知道"下一步要做什么"
- ✅ 关键决策有理由，不是只有结论
- ✅ 文件路径可访问
- ❌ 不要事无巨细，记日志不是记流水账

## 开新线的判断标准

### 条件对照

| 条件 | 应该开新线 | 不应该开新线 |
|------|-----------|-------------|
| 话题完全切换 | ✅ 聊完 A 要聊 B，各走各的 | ❌ 还在深度讨论同一个话题 |
| 需要保持独立状态 | ✅ 两个项目并行推进 | ❌ 单一调研还在进行中 |
| 角色不同 | ✅ 调研角色 vs 执行角色 | ❌ 相同角色的延续 |
| 对话已接近上限 + 还要继续 | ✅ 先写盘再开新线 | ❌ 还有大量容量继续聊 |

### 开新线标准流程

```
1. 确认当前对话的状态 → 读 SESSION_LOG
2. 判断是否该开新线 → 用条件对照表
3. 写盘（开新线前必须完成）
4. 打包新线启动指令（角色+文件路径+工作方式+回传要求）
5. 开新对话，粘贴启动指令
```

## 最小文件架构

```
项目目录/
├── SESSION_LOG.md         # 当前对话的状态日志
├── records.md             # 项目级完整盘记录
└── 共享知识库.md          # 全局上下文（所有对话共用）
```

这三层文件覆盖了"对话的记忆不丢失"的基本需求。SESSION_LOG 管会话级状态，records.md 管项目级沉淀，共享知识库管全局上下文。每层职责独立，不互相覆盖。

## 快速检查清单

**写盘前问自己：**
- [ ] 当前的关键进展写了吗？
- [ ] 做了重要的决策吗？理由写了吗？
- [ ] 下一步要做什么，写清楚了吗？
- [ ] 如果这个对话现在截断，新来的能直接接上吗？

**开新线前问自己：**
- [ ] 当前对话的 SESSION_LOG 更新了吗？
- [ ] 新线需要的上下文在磁盘上吗？
- [ ] 新线的职责和工作方式写清楚了吗？
