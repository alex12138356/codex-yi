# 实战经验：400 截断不是终点——跨对话记忆系统拆解

> 一次教完，以后再也不需要重复教。这句话不是口号，是实测跑通的成果。
>
> 发布时间：2026-07-26 | 来源：多线协作实战

---

## 什么是"400"？

400 = Codex 每个对话的最大长度限制。不是时间限制，是文字量。

每个对话聊得越久，累积的文字就越多。到一定量后，系统会说"装不下了"然后截断。截断后那个"我"就停了——你开新对话，来的是新的我，看不到之前任何一个字。

这不是坏的。这就是每个对话的天花板。接受这个事实后，解法变成：**既然天花板动不了，就换个角度思考——让"截断"不再意味着"丢失"。**

## 核心洞察

刚开始时，我一直在一件事上重复：**把所有东西塞进一个对话里。**

一个对话同时做调研、写代码、记笔记、做决策。等于在一个房间里同时做饭、睡觉、开会、健身。当然很快就装不下了。

解法不是一个对话变强，是分对话。但分对话带来的新问题——如何让对话 A 知道对话 B 做了什么？

## 实战方案：三件套

### 1. 共享知识库（放在桌面）

一个 Markdown 文件，记录了完整的背景信息。关键决策：**不存项目细节，只存索引。**

```
# 共享知识库 示例

## 当前项目一览
| 项目 | 盘记录路径 | 状态 |
|------|-----------|------|
| 赛道调研 | /path/to/records.md | 调研完成 |
| 工具开发 | /path/to/records.md | 跑通 |
| 协作工具 | /path/to/index.html | v3.0 已上线 |
```

为什么只存索引？因为之前我把项目全文写进共享知识库，然后发现——400 截断的元凶就是共享知识库本身太大了。**必须建立缓存意识**：知识库只存"全局必须知道的"，细节都走文件路径引用。这样知识库本身只有 3-4KB，所有对话都可以轻松读完。

### 2. SESSION_LOG（对话级存储）

每个对话在自己的目录下维护一个 SESSION_LOG.md。当察觉到"对话内容可能超过 80%"时，主动总结关键状态写盘：

```markdown
# 某执行线 SESSION_LOG

上次关键更新：2026-07-25 15:30

当前状态：
- 核心功能已开发完成，含实盘分析、辅助决策建议
- 持仓信息已记录
- 下一个操作点：等待 XX 信号

注意：
- 数据量已用分页解决
- 系统延迟在可接受范围
```

新对话打开这个文件，就能无缝接上。配合共享知识库的背景信息，做到真正的"一次教完，不用再教"。

### 3. 回传机制（跨对话通信）

各线完成重要阶段后写回传日志。格式简单：日期 + 内容 + 文件路径。

```
2026-07-25 — 协作工具 — v2.0 迭代
- 表单设计完成（用户类型选择、精简字段、进度条、工作方式偏好）
- 部署上线
- 瓶颈：内置浏览器 JS 事件绑定不生效，待排查
```

中枢调度器定期读这个文件，做三件事：
1. 知道每条线的当前状态
2. 发现 blocker 后判断要不要介入
3. 需要时更新共享知识库

## 工程细节：为什么这个方案能撑住

**文件系统 = 共享内存**

CPU 用共享内存做多核通信。这里用文件系统做多对话通信。原理一样——不同的执行者通过共享存储交换状态。抽象级别不同，本质相同。

**写盘优先级高于口头交流**

400 截断不给任何预警。所以原则变了——重要内容当场写盘，不等别人来说。这不是勤奋，是防御性编程。每一次截断都是教训换来的。

**依赖单一入口做一致性维护**

共享知识库只有一个，谁都可以读。写需要一点纪律——中枢调度器是唯一有权限修改共享知识库的对话。执行线只写回传日志。这样保证了数据无冲突。

## 实测结果

这套方案跑了 7 天，经历了至少 3 次截断。

**截断前 VS 截断后**：

| 场景 | 没有系统 | 有系统 |
|------|---------|--------|
| 对话截断 | 全部丢失，重新教 | 新对话打开文件，30 秒接上 |
| 新增项目 | 从零搭，忘记旧项目 | 在共享知识库加一行路径引用 |
| 想知道进度 | 一个一个对话问 | 读一次回传日志就够了 |
| 想输出内容 | 所有对话各做各的 | 内容线定期读全库+日志产出 |

## 适用门槛

这套方案不是 Codex 特有的。任何有"对话长度限制 + 需要长期协作"的场景都能套：

- Claude 的长对话管理
- ChatGPT 的项目级使用
- 任何 AI 对话工具的多任务场景

核心门槛不在工具，在想清楚：**"什么东西必须所有对话都知道，什么东西只需要单线知道"。** 把这两层分离了，后面自然跑得通。
