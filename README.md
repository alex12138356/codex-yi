# Codex 壹 · 一次教完，不用再教

你的 Codex 对话是不是总在关键时候被截断？开了好几个线但每条都要重新教一遍你是谁？

**Codex 壹** 是一个模板生成器——填一次你的背景、目标、工作方式，自动输出一套完整的多线系统配置：

- **中枢调度** — 多个对话线统一管理，一个中枢统揽全局
- **跨对话记忆** — 共享知识库模板，填一次背景，所有对话自动继承
- **400防护** — 关键笔记自动写盘，断线不丢上下文
- **统一回传** — 各线执行完自动写回传日志，你不需要人肉传话

适合：用 Codex/Claude 做项目的个人、小团队，尤其是被单线程限制搞烦了的重度用户。

---

## 快速开始

1. 打开 https://codex-yi.com（或直接用 index.html）
2. 填表：你是谁、目标是什么、打算开几个线
3. 一键导出配置包，解压到你的项目目录
4. 开新对话，把生成的任务描述贴进去——开干

全程 5 分钟。

---

## 它解决什么问题

大多数人用 AI 助手的方式是：开一个对话，聊到截断，失去上下文，重开，再教一遍。

**你不需要这样。**

这套系统把"身份信息"和"任务执行"分开存储。身份信息写进共享知识库（一个文件），所有对话公用。你只需要填一次。
